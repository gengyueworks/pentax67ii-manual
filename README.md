# PENTAX 67II 中文说明书 · 网页学习版

> 一台 1998 年的中画幅胶片机，值得拥有一份随时可查的中文说明书。

## 这是什么

PENTAX 67II（宾得 67II）中文说明书的全套资料整理：

| 文件 | 说明 |
|------|------|
| `Pentax67II中文说明书.pdf` | 官方中文说明书，80 页，28.7 MB |
| `Pentax67II中文说明书.epub` | 自制的 EPUB 版本，适合手机/阅读器 |
| `pentax67-manual/` | 说明书逐页图片（80 张 JPG，网页版用） |
| `index.html` | 网页学习版：目录导航 + 分页阅读 + 学习路线 |

## 网页版功能

打开 `index.html` 即可离线使用：

- 学习路线图（从认识机身到进阶拍摄）
- 分页阅读，页面图片高清展示
- 章节导航快速跳转

## 关于 PENTAX 67II

1998 年发布的 6×7 中画幅单反，6×7 画幅、TTL 测光、模块化后背，是胶片中画幅里最经典的「大块头」之一。至今仍有大量摄影师在使用它拍摄风光与人像。
