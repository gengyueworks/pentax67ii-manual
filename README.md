# PENTAX 67II 官方说明书与中画幅摄影指南 · 交互画廊版

> 诞生于 1998 年的日本旭光学（PENTAX）中画幅单反终极名机，值得拥有一份随时可查、由浅入深的殿堂级中文全景手册与实战进阶指南。

## 项目概述

PENTAX 67II（宾得 67II）官方中文说明书全套资料与交互式学习站：

> **在线体验与画廊（GitHub Pages）：https://gengyueworks.github.io/pentax67ii-manual/**

| 文件 / 模块 | 说明 |
|------|------|
| `Pentax67II中文说明书.pdf` | 旭光学（PENTAX）原厂官方中文说明书，80 页高清全本，28.7 MB |
| `Pentax67II中文说明书.epub` | 精装重排版 EPUB 电子书，18.0 MB，适配 Apple Books / 微信读书 |
| `pentax67-manual/` | 官方说明书 80 张逐页切图（page_01.jpg ~ page_80.jpg） |
| `index.html` | 交互式全景学习站：支持中文/英文/日文三语切换、黑白双主题、关卡式单步推进、80页手势翻页画廊与一键离线下载 |

## 网页版核心功能

- **三语无缝切换**：支持 🇨🇳 简体中文 / 🇺🇸 English / 🇯🇵 日本語 即时切换；
- **黑白双主题**：默认「☀️ 银盐画册白」，支持一秒切换「🌙 暗室黑金」；
- **四大阶段关卡式推进**：启航准备 ➔ 首卷实战 ➔ 精准曝光 ➔ 进阶绝技（MLU 预升/多重曝光/故障速查）；
- **80 页原版说明书沉浸式阅读器**：支持单页精读、双页跨页展开、10 大章节一键直达、全屏无损灯箱与手机端左右滑动翻页手势；
- **经典 120 胶卷档案**：Kodak Portra 400/800、Tri-X 400、Fuji PRO 400H、HP5+、Velvia 50 实战搭配指南；
- **纯静态直接下载**：一键秒存 28.7MB 官方完整 PDF。

## 关于 PENTAX 67II

1998 年由日本旭光学工业株式会社发布的 6×7 中画幅单反相机巅峰之作，拥有 56×67mm 巨大底片面积（135 全画幅的 4.5 倍）、TTL 六分区多模式测光系统与传奇的 SMC Pentax 67 镜头群，至今仍是全世界无数摄影大师创作的核心工具。
